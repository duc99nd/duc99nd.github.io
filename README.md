# Duc Trinh - Personal Portfolio

This repository contains the source code for my personal portfolio website, hosted on [GitHub Pages](https://duc99nd.github.io).

## Overview

A responsive, single-page portfolio built with:
- **HTML5** for semantic structure
- **Vanilla CSS3** featuring Glassmorphism, Dark Mode, and CSS Grid/Flexbox
- **Vanilla JavaScript** for scroll animations (IntersectionObserver) and smooth navigation

## Local Development

To run this project locally, simply open the `index.html` file in any modern web browser, or serve it using a local HTTP server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js (npx)
npx serve
```
